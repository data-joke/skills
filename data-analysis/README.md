# Data Analysis Skill

数据分析专家 skill：当用户提供表格数据、要求分析数据/计算商业指标/诊断数据异动/交付分析报告时触发。遵循一套标准的分析 SOP，将数据转化为可直接指导行动的结构化商业报告。

## 介绍

支持的能力（方法论覆盖）：

- **链路转化**：AARRR 海盗模型、AIDA 爱达模型等单向或漏斗转化。
- **对比分析**：绝对值、百分点（pp）、同比/环比百分比变化。
- **异常分析**：变异系数（CV）、Z-Score、四分位象限法。
- **趋势与周期**：季节性（Seasonality）、工作日效应及外部突发事件影响。
- **维度拆解（MECE）**：数值列分层前必先运行 Python 查看频数分布，严禁粗暴等宽/等频分层。
- **相关与预测**：Pearson/Spearman 相关性分析、回归建模。
- **结构化报告**：3-5 条核心发现 + 分析子模块 + 带 **ICE 评分**（Impact/Confidence/Ease，1-5 分）的行动清单 + 数据标注。
- **单文件 HTML 报告**：前端图表库源码全内嵌、零外部 CDN/图片，Python 注入纯 JSON 数据动态渲染。

**适用场景**：对订单/GMV/留存/转化等业务数据做"探查 → 分析 → 出报告"的完整流程，交付可直接用于决策的报告（Markdown / 单文件 HTML / Excel 等）。

**铁律（Skill 内置）**：
- 所有数据处理与计算必须编写 Python 并执行，禁止用大模型推理做数学运算。
- 最终报告中每个数字/百分比须与 Python 执行结果二次对账（100% 自检）。
- 边界数据、样本量不足（N<30）、信息不全时，必须显式声明"【存疑声明】"，不歪曲事实。

## 安装教程

> 假设你收到的就是本文件夹 `data-analysis/`。

**1. 放置技能目录**

- **Claude Code**：放到 `~/.claude/skills/data-analysis/`（也可放项目 `.claude/skills/` 下）。
- **其他 Agent**：按其技能/规则机制加载 `SKILL.md` 即可；本 skill 为纯指令型，**无需安装任何依赖**（运行时依赖本机 Python 3 + pandas/numpy 等常用库）。

**2. 使用**

以 Claude Code 为例，直接把需求丢给 AI 即可触发，例如：
- "帮我对订单表做一份数据分析报告，输出 HTML"
- "看下这周 GMV 为什么跌了，分析一下原因"
- "帮我按渠道算一下转化率和留存"

**3. 业务口径模板（可选，强烈建议）**

`references/Business_Overview.md` 是一份**业务全景与口径定义手册模板**，用于在分析前对齐核心指标公式（活跃/留存/转化/LTV/CAC 等）、维度分层标准和业务波动基线。将 `[如：…]` 占位符替换为你业务的真实口径后，分析会自动以该文件为唯一准绳，避免 AI 自创口径。

## 工作流速览（SOP）

| Step | 名称 | 要点 |
|---|---|---|
| 1 | 需求澄清与口径对齐 | 业务目的/核心指标口径/数据范围/字段含义，未对齐前禁止往下走 |
| 2 | 数据理解与质量清洗 | `df.info()`/`head`/`isna` 物理探测，异常需出《数据质量异常报告》 |
| 3 | 选择分析方法 | 以需求为导向选方法论（转化/对比/异常/趋势/拆解/预测） |
| 4 | 数据解读与因果归因 | 数字翻译为业务语言 + 反事实检验 + 必要时联网情报 |
| 5 | 结构化商业报告 | 核心发现 → 分析子模块 → ICE 行动清单 → 数据标注 |
