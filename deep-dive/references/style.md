# 风格规则

## 术语

- 首次出现：术语 + 一句话通俗解释（括号或破折号），之后直接用术语
- 例：Prompt Caching（提示词缓存——把对话里重复的开头部分暂存复用，省时省钱）
- 称呼全篇统一：首次"英文（中文——解释）"后，全篇固定用其中一种，不中英混叫
- 解释要说到"它解决什么"，不要复读术语字面

## 简洁（删词检查）

原则：10 个字能讲明白，不用 11 个字。词表分两类：

**无条件删除**：
- 口头禅：需要注意的是 / 值得注意的是 / 事实上 / 我们知道 / 值得一提的是 / 总而言之 / 简而言之 / 众所周知 / 总的来说 / 综上所述 / 不难发现
- 空话：没有信息量的过渡句、总结句
- 重复解释：同一概念解释第二遍
- 句式级 AI 腔：连续多段同构开头、"不是X而是Y"句式堆叠、滥用破折号；以及"在当今背景下 / 随着…的发展 / 赋能 / 底层逻辑 / 本质上"
- 被动句改主动句，长句拆短句

**需限定或替换**：
- 含糊量词：大量 / 普遍 / 许多——落实为具体数字；拿不到数字时，若属于术语（如统计意义的"显著"）或有来源支撑的定性结论则保留并注明，否则删整句
- 引用原文或引用术语时豁免机械扫描

一句话只说一件事。成文后先机械后人工：对词表全文扫描，命中逐处处理；再逐段通读，专删不减义的字词。

## 数字

- 比较性数字（占比/倍数）必须带参照系（行业平均、上一代、竞品、未配置时的默认值）——补不上参照系的删
- 事实性数字（默认值、配额、延迟等）不需要参照系，但必须能在研究笔记溯源
- 例："占 34%" → "占 34%（行业平均 22%）"；"TTL 默认 5 分钟"直接保留，无需对比

## 真实性表达（五档，与 research.md 一致）

- 有源事实：直接陈述（来源按笔记 ID）
- 来源冲突："A 说…（T级）/ B 说…（T级）"并列，不裁决
- 推断：明写"推断：（依据是笔记 #N…）"
- 未证实：明写"未查到官方说明"
- 声明 vs 实测：分开标注
- 标注格式全篇统一，不靠读者猜；五档不得混用——不确定的内容禁止使用确定语气

## 语调

- 学习笔记气质，兼顾可发布：直接、平实，不端着
- 不用反问句堆气氛，不用感叹号渲染
- 举例服务于理解机制，不为凑篇幅
