# deep-dive — 深度研究文章 Skill

> 给定任意领域的主题或概念，让 agent 走一条**"先研究、后写作、再审查"**的流水线，产出**专业、真实、系统、有深度、能联想**的中文研究文章。

适用于：技术、科学、商业、历史、政策、方法论……任何你想"彻底搞懂并写下来"的主题。任何支持 skill 机制的 agent 均可使用。

```bash
/deep-dive 我想深度了解下ai大模型的缓存机制，帮我写篇文章

# 或自然语言触发
"研究一下X" / "深入讲讲X" / "X是怎么运作的"
```

## 为什么需要

大模型直接"写篇关于 X 的文章"，本质是凭训练记忆生成：机制描述、价格数字、版本行为全是待验证假设，还自带一脸自信——文章不可靠的根源就在这里。

本 skill 把"真实"从态度变成机制，只有三条铁律：

1. **先研究，后写作**——研究笔记先于文章存在，且是文章唯一事实依据，笔记里没有的不写；训练记忆先打 `[记忆假设]` 标签，核验通过才能进正文；
2. **每个论断可回溯**——关键论断有明确定义（TL;DR/机制/数字版本定价/对比/场景推演五类），逐条编号；信源按 originator 判独立，支撑记录必须含逐字引文+定位符；
3. **产出者 ≠ 审查者**——成稿后由一个全新独立 agent 只凭"文章+笔记+任务卡"做攻击式审查，含全量来源核对与原文回访。

## 流程

```mermaid
flowchart LR
    A[定档确认] --> B[输入澄清]
    B --> C[解构主题<br/>研究提纲+体裁判定]
    C --> D[多源联网研究<br/>强制搜反方+后继探测]
    D --> E[交叉验证<br/>研究笔记(论断ID制)]
    E --> F[成文<br/>按体裁骨架与风格规则]
    F --> G[独立审查<br/>fresh agent攻击]
    G --> H[修复+自检]
    H --> I[存档]
```

## 三档

| 档 | 触发词 | 字数 | 搜索预算 | 回跳补搜上限 | 独立审查 |
|---|---|---|---|---|---|
| 快速 | "快速过一下""简单讲讲" | ≤1500 字 | ≤5 次 | ≤1 处 | 跳过（报告注明风险） |
| 标准 | 默认 | 2000-4000 字 | 8-15 次 | ≤3 处 | 必做 |
| 深挖 | "深挖""彻底搞懂" | 4000-6000 字 | 15-30 次 | ≤5 处 | 必做 |

档位确认制：用户原话有明确档位信号 → 直接采用；由 AI 推断的档位 → **开工前必须确认一次**再跑。按体裁选骨架：技术深潜（默认）/ 科普解释 / 决策参考 / 历史政策。

## 研究阶段的关键机制

| 机制 | 说明 |
|---|---|
| 关键论断定义 | = 支撑 TL;DR/机制解释/数字版本定价/对比/场景推演的断言；逐条编号、打关键/背景标签，防归类逃逸 |
| 信源分级 | T1 一手只能单独支撑"该主体如此声明"类断言；实际表现/争议事实需交叉验证。维护者/当事人内容按 T1 处理并标注立场 |
| 独立 = originator | 同一新闻稿被多家改写、同一主体多渠道发布，只算 1 个信源 |
| 逐字引文 | 支撑记录四字段：URL + 访问日期 + 原文 quote + 定位符——编造难度远高于转述，且可被抽查 |
| 强制搜反方 | ≥2 条查询词 + 结果概况 + 采纳/不采理由入笔记，可审计；纯概念主题可显式豁免 |
| 后继探测 | 先写明系统当前日期，再搜"X latest + 当前年月"；当前版本必须落到官方 changelog/release notes |
| 时效窗口 | AI 3-6 月 / 云与前端 6-12 月 / 语言数据库 1-2 年 / 政策法规每次必核 / 商业数字按财报周期 |
| 确定性五档 | 有源事实 / 来源冲突（并列≠等权）/ 严格推断（依据只能是已编号的有源前提）/ 未证实 / 声明 vs 实测 |

## 审查阶段

独立 agent（禁止 fork 或继承会话上下文）拿到 `article.md + research-notes.md + 任务卡`（问题/受众/档位/体裁），任务是**攻击而非润色**：

1. **全量来源核对**——文中每个关键论断逐条按 ID 回查笔记，不做抽样
2. **原文回访**——抽 3 条（深挖档 5 条）最关键/最可疑的论断，重新打开 URL 核实逐字引文与定位符
3. **攻击推导链**——场景推演的结论从机制真的推得出吗？
4. **结构层**——体裁骨架是否服务主题、TL;DR 与正文一致性、局限与反方是否缺失

事实级必须修：补搜 / 降级存疑 / 删除三选一；事实错误 >20% 或核心章节失守 → 研究阶段返工。修复后复审一轮（最多 2 轮）。

## 产物结构

```text
~/articles/<YYYY-MM-DD-主题slug>/
├── article.md         # 成稿（关键论断带 [n] 引用编号）
└── research-notes.md  # 研究笔记（论断 ID 表 + 全部来源 + 反方搜索块 + 更新记录）
```

文章骨架（技术深潜默认）：TL;DR（固定四要素）→ 问题背景 → 原理 → 场景推演（变量矩阵法）→ 对比与联想 → **局限与适用边界** → 常见误区 → 深挖路径 → 参考。

## 实战案例

**《大模型的三层缓存：KV Cache、Prompt Caching 与语义缓存》**（2026-09-06，深挖档）：

- 20+ 次检索，21 个一手来源（6 家厂商官方文档 + 5 篇 arXiv 论文 + vLLM/GPTCache 官方仓库）
- 独立审查回访 7 个原文页面：数字层零错误，但抓出 **13 个事实级问题**——包括 2 处引用失实、1 处 TL;DR 数值归属错误、3 个会误导读者实际操作的错误结论，全部修复后才交付
- 审查的价值正在于此：写作时的"我以为"和原文之间，永远存在偏差

## 安装

本 skill 遵循 [Agent Skills 开放标准](https://agentskills.io)。推荐放入跨客户端约定目录（Codex / Cursor / OpenCode / Amp 等会扫描）：

```bash
~/.agents/skills/deep-dive/
```

| Agent | 能否直接读 `~/.agents/skills/` | 做法 |
|---|---|---|
| Codex / Cursor / OpenCode / Amp 等 | ✅ | 放入即可 |
| Claude Code | ❌ 只加载 `~/.claude/skills/`（官方支持链接目录） | 见下方链接命令 |

```powershell
# Windows（junction，无需管理员）
New-Item -ItemType Junction -Path "$HOME\.claude\skills\deep-dive" -Target "$HOME\.agents\skills\deep-dive"
```

```bash
# macOS / Linux
ln -s ~/.agents/skills/deep-dive ~/.claude/skills/deep-dive
```

或把下面这段发给你正在用的 agent，由它自行安装：

```text
请为当前环境安装 deep-dive skill：
1. 克隆仓库 https://github.com/data-joke/skills.git 到临时目录；
2. 把其中的 deep-dive/ 目录完整复制到你加载 skill 的目录，目录名保持 deep-dive；
3. 完成后报告安装位置，并确认你能读取到其中的 SKILL.md。
```

依赖：agent 具备联网检索与网页抓取能力；启用独立审查需支持 spawn 子代理。联网失败时未核验内容按"推断/待验证"降级标注并告知，不会静默跳过核验。

## 文件说明

```text
deep-dive/
├── SKILL.md                  # skill 主指令（档位确认、8 步流程、失败降级）
├── README.md                 # 本文件
└── references/
    ├── research.md           # 研究规范：关键论断定义、信源分级、笔记模板、确定性五档
    ├── structure.md          # 文章骨架：四体裁、变量矩阵法、局限与适用边界
    └── style.md              # 风格规则：术语统一、删词词表、数字两类、五档表达
```

## 设计原则

1. **机制优先**：不是"怎么用"，是"怎么运转、为什么这样设计"；机制表述必须标注适用对象（哪家产品 × 哪个版本）
2. **验证体系有总开关**：关键论断有定义、逐条编号、标签可审计——防"形式合规、实质造假"
3. **深度与联想有硬指标**：深度 = 机制拆解 + 变量矩阵法场景推演；联想 = 相邻概念辨析 + 跨域类比（必须说明失效点，找不到合适类比就省略并记录原因，禁止硬凑）
4. **确定性五档不升级**：文中确定性 ≤ 笔记档位；推断的依据只能是已编号的有源前提
5. **成本可控**：三档有搜索预算与回跳上限，超限即停并报告，不静默膨胀
